# 🤖 AI for Scrum Masters — Project TLDR

## 🧩 What it is
A two-part exploration into making AI useful for **Scrum Masters at Netcetera**:

1. **A "TLDR: AI Basics" primer** — a quick, no-jargon intro to AI and the
   buzzwords flying around (LLMs, agents, prompts, RAG, etc.) so SMs can get up
   to speed fast.
2. **Hands-on tooling** — figuring out how everyday AI tools
   (**Microsoft Copilot, ChatGPT, Miro AI**) can actually support a Scrum
   Master's daily grind — starting with the repetitive, data-shuffling work that
   eats time but adds little value.

> **The bet:** SMs spend a lot of time *collecting, summarizing and reshaping*
> information. That's exactly what AI is good at — so let's offload it.

## ✅ Done
- 📘 **"TLDR: AI Basics – Quick Overview"** — drafted and ready as a fast
  on-ramp to AI concepts for the team.
- 🛠️ **Capacity Agent (v1, in progress)** — started building an agent that
  produces a **weekly capacity overview across the three teams** in my value
  stream, aimed primarily at **vacation planning**.

## 😵 What gave me pain
- Getting an agent to **summarize and structure input data into a *specific*
  output format** is harder than it looks.
  - It's not the "understanding" that's tricky — it's the **consistency and
    shape** of the result. Free-form input → strictly-structured output is where
    the friction lives (exactly the kind of thing that needs clear schemas,
    examples, and guardrails in the prompt).

## 🚀 Where I want to continue
- 📊 **PI Planning Capacity Agent** — capacity broken down **per team and
  skill**, **per sprint**, including **reductions** (vacation, holidays,
  part-time, etc.).
- 🗂️ **Titrakk Summary Agent** — auto-summarize **Titrakk information per team**.
- 📝 **Team Notepads** — lightweight, AI-assisted notepads to make it easier to
  **draft a release plan** for each team.
